==========================================

This file covers the Microsoft Visual C++ runtime and OpenSSL libraries added
by RiaCore's desktop packaging. Components retain their respective licenses;
RiaCore's own license does not replace or grant additional rights to them.
The complete generated release inventory and copied upstream license/notice
texts are in licenses/inventory.json and licenses/THIRD-PARTY-LICENSES.txt.
RiaCore's public-release GPL text is supplied as LICENSE and
licenses/RiaCore-LICENSE.txt. Source locations are in licenses/SOURCE-CODE.txt.

OpenSSL 3 (macOS packages)
-------------------------

Copyright The OpenSSL Project Authors and other contributors.

The macOS package includes libssl.3.dylib and libcrypto.3.dylib used by the
native database module. OpenSSL 3 is licensed under the Apache License,
Version 2.0. The license text, author information and any upstream NOTICE
file accompanying the build are supplied in native-libs/ as
OpenSSL-LICENSE.txt, OpenSSL-AUTHORS.md and, when present,
OpenSSL-NOTICE.txt.

RiaCore packaging changes Mach-O library identifiers and load paths to resolve
dependencies within the app bundle, may remove unused architecture slices,
and signs the packaged libraries. These packaging changes do not change the
OpenSSL source code. This paragraph records that the distributed binaries
have been modified during packaging.
